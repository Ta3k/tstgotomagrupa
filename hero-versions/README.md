# Hero versions

- `hero-version-2.jekyll.snapshot` and `hero-version-2.scss.snapshot` preserve the complete atom/orbit hero.
- Restore these files when asked to “get back to version 2 of hero”.
- `hero-version-3.jekyll.snapshot` and `hero-version-3.scss.snapshot` preserve the morphing gold-ribbon hero.
- Restore these files when asked to “get back to version 3 of hero”.
- Version 3 predates the continuous gold-thread journey. A full version 3 restore also removes the `Continuous gold-thread journey` blocks from `site/js/common.js` and `_sections.scss`.
